# Maintainer guides

How the JianZiPu font is looked after: from a tester's Change Request to a
released font, and the services behind it. Start with [CONTRIBUTING.md](../../CONTRIBUTING.md)
if you want to help rather than maintain.

- [reviewing.md](reviewing.md): deciding on Change Requests and testers' drafts
- [releasing.md](releasing.md): release candidates, publishing a release,
  versions, scope rules, troubleshooting
- [setup.md](setup.md): one-time setup of your computer, Supabase, Railway,
  Resend, GitHub, Cloudflare Pages and MailerLite

Elsewhere:

- [CHANGELOG.md](../../CHANGELOG.md): what each version changed
- [builder/README.md](../../builder/README.md): how the build works (the
  pipeline, the inputs, the hosted pilot's architecture)
- The Builder's own Help page (`/help`): the guide for everyone who uses the
  Builder, testers included

The rest of `docs/` is the maintainer's local working notes (UX specs,
wireframes, the roadmap) and isn't in the repository. Only this folder is.
