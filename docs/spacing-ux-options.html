Spacing panel: five options, drawn

Lo-fi wireframes of docs/SPACING-UX-OPTIONS.md. Same five options, same recommendation, pictures instead of ASCII.

Why spacing is hard

A word is a stack of parts and most parts can be left out, so "the part above me" is a question, not a fact: for the Stroke it is 急/綽 if present, else Position/Finger, else 泛音, else nothing. The data answers that with an ordered list of rules per part, first-present-base-wins, and eight of those rules also carry a seven-row exception list keyed on the stroke glyph. That is 37 rules and ~70 exception rows for one word type, shown today one part at a time.

Two regularities make it tractable. Finger and Position sit side by side and share identical rules, so the Standard word is really five tiers (泛音 · Finger+Position · 急/綽 · 注+Stroke · String). And every exception list uses the same seven stroke families (打摘/勾剔 · 劈/掐起 · 挑/托 · 抹/抹挑/掩/輪/半輪 · 勾/大 · 剔/摘 · 歷), so there is one classification of strokes, not eight.

How you read it. Scan a row left to right and you read the search order: "Stroke sits under 急/綽 if there, else under Finger/Position, else under 泛音, else starts at -30". The ● cell is the canvas arrow. Holes (注 has no rule after 泛音) are visible as "–".

  • Create a rule: click an empty cell → gap 0 with default edges. Exception: "by glyph ▾" opens the existing list inline under the row.
  • Order: implied by column order (nearest above first); a rule out of that order gets a ①②③ superscript and an Advanced reorder.

ConIt is a spreadsheet, not a picture; Horizontal is a second table; exceptions still a click away.

How you read it. Top to bottom is the word. Every number on screen is in effect right now, and the chip's sentence ("gap above Stroke, after 急/綽, for 勾/大") is the same sentence as the canvas arrow and the undo label. Side-by-side parts are one tier.

How you read it. Each group is one rule; the cards under it are the word shapes that rule governs. A shape appears only under the first rule whose base it contains, so the "first match wins" order becomes something you can see.

  • Change a gap: the field under a group; click a card to load it into the main canvas for drag editing.

ProMakes the rule order visible; excellent for coverage and QA ("which shapes hit otherwise?"); thumbnails exist already.

How you read it. A row is "what 歷 does to the word"; a column is "the gap above Stroke, after 急/綽, for every stroke". The ● row × the selected column is the canvas arrow.

  • Change a gap: type in a cell (one exception row's value), or drag on the canvas (edits the ● cell of the active column).
  • Families: "+ family" adds a row to all eight lists at once; dragging a glyph chip between rows moves it in all eight; deleting a row asks "fold into otherwise?".
  • Order: immaterial — families are disjoint, so hiding the list order costs nothing. If a list diverges from the shared partition, its column shows "split" cells with a disclosure to the raw list.
ProThe author's actual mental model ("勾 sits lower than 挑"); 56 numbers in one table instead of eight scattered lists; consistency is structural.
ConCovers only the 8 glyph-dependent rules; a second view, not the Spacing panel. Empty for Chord and Vertical words.

Recommendation: B + E, with A under Advanced

Build the ladder as the Spacing panel, the stroke table as a second tab, and keep the matrix as the Advanced "all rules" view that replaces today's raw list. Skip C (its value — seeing which shapes a rule governs — comes cheaper from the ladder's Try-without chips and shape counts) and D (its one strength, edge choice, is an Advanced detail).

Glyph tray: all glyphs of the selected part, under the canvas

The author wants, with a part selected, to see all its glyphs and add, remove, edit them. Putting the member grid in the inspector would bury the Spacing panel (147 Position glyphs ≈ 20 rows); a slide-over of the Areas screen would cover the canvas. So: a strip between the status line and the Test words, in the wide canvas column, next to the thing it changes. Clicking a glyph sets the preview; Manage turns on remove / add. It edits the area, shared by every word type, and says so.
