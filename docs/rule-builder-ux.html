3 · The rule editor (click a row, or + new rule)

The editor takes over the canvas; it does not open beside it. The preview you drag in is the canvas, with the other parts dimmed. The inspector swaps the rule rows for two glyph pickers. The canvas already has the drag, the arrow and the page, and a second small preview beside it would mean two places to look. Esc or Cancel brings everything back.

The example: you open + new rule under after Position. The canvas shows the word the way this rule sees it: 急/綽 left out, Position solid and fixed (the base), Stroke free to drag, the rest faded.

4 · How the editor sits with the canvas

same screen, two modes
  • Outside the editor nothing changes: drag the box = change the ● row's number; drag an ○ handle = add a pill; click a grey ghost arrow = look at that pill's rows (and the preview drops the parts before it).
  • In the editor the canvas only lets you drag the Stroke up and down; every other part is faded and locked. The arrow from Position's bottom edge reads the gap live; the number box on the right follows.
  • "give 勾 its own gap" (the checkbox today) becomes the + new rule for 勾 button: it opens the editor with 勾 already ticked.
  • Undo: a confirmed rule is one undo step ("Stroke after Position: new rule 1").

While dragging: "no change: 剔 摘 are in no row above". If the move would change something, the row it steals from flashes red and the line says which glyphs move.
otherwise has no handle and nothing can be dropped below it. Its number is typed like any other. Delete it only in Advanced (then unmatched glyphs are not placed, shown as a warning).
Typing a number in a row changes only that number; the ● row also moves on the canvas while you type.

Horizontal and the other parts

Same panel on the ⇆ tab, and for every part. For 注 and String the stroke is the base (注 sits beside the Stroke), so the rows read "when Stroke is [勾][大] → 77" and 注's own column is hidden, because 注 has only one glyph. A column is shown only for a side that has more than one glyph.

7 · What changes in the current app

Kept

  • WordCanvas: red active arrow, grey ghosts, ○ edge handles, drag edits the ● row. Adds: dim-others, overlay stack, base marker.
  • GlyphTray, TestStrip, CenterPanel (hidden only while editing a rule).
  • GapEditor's logic: shadow detection, active-row match, otherwise handling. It now drives the rows and the warnings.

Replaced

  • RuleBox under the canvas → RulePanel at the top of the inspector (chain + rows).
  • GapEditor's dropdown list and GlyphSetPicker popovers → RuleEditor (two grids, presets, search, gap, Confirm).
  • "give X its own gap" checkbox → "+ new rule for X".
  • SpacingPanel under Advanced → gone; chain drag covers order, edges in the pill's right-click menu.

Moved

  • StackPanel while a part is selected → one-line word strip on top + "Structure ▸" fold. Unchanged when nothing is selected.

Not drawn yet

  • Editing the same stroke groups in all four Stroke rules at once (the seven groups repeat in after 急/綽, Position, Finger, 泛音). Could be a checkbox in the editor: "use these groups in the other 3 rules too".
  • Finger and Position have identical rules today; the chain could show them as one linked pill. Left out to keep this page about the editor.
  • The Vertical word's "previous row" base.
