How to type

Type each character the way you read it, in 中文 or ASCII. Under each example in grey: the same in ASCII.

1A space between characters

Typed in ASCII, a character takes its own width: put a space between characters, and each extra space leaves an empty cell. Typed in 中文, a character has no width of its own: press space after each one, the last too, or type # before each.

In Chrome and Word

In Chrome, or wherever characters overlap, type the word in Chinese: 带起 rather than daiqi. While you type in ASCII, Chrome can redraw only the end of a word. Cutting the text and pasting it back puts it right.

Keep each character in one script: 勾3 or k三 may show in a browser but not in Word.

Using the font in Sibelius, Dorico or MuseScore

There the spacebar moves lyrics to the next note. In ASCII, type the character and press space to move on. In 中文, type # before each character. To put two characters on one note, join them with + in ASCII, or type them one after the other with # in 中文.

  • k7 → k7
  • #勾七 → #勾七
  • :fanqi+s9u6 → :fanqi+s9u6 two characters, on one note.
  • #：泛起#名九挑六 → #：泛起#名九挑六 the same, typed in 中文.
  • If a character shows as an empty box, it has no width: in 中文, check that it starts with #.
Using the font in Word or on a web page
  • In Word, open the Font dialog and set both the Latin text font and the Asian text font to JianZiPu. On its Advanced tab, set Ligatures to Standard Only and tick Kerning for fonts. Without these Word shows the letters you typed.
  • In Word, turn off the AutoCorrect option that capitalises the first letter of a sentence: s and S are different characters.
  • In Word, typing in 中文: press space after each character. Word cannot join # to the character after it. The last character on a line can run past the margin; press Shift+Enter before it.
  • PowerPoint may show the letters you typed, not the notation. Set the notation in Word and paste it into the slide as a picture.
  • On a web page, give the notation word-break: keep-all so Safari keeps a character typed in 中文 whole, and white-space: pre-wrap so extra spaces stay as empty cells. Leave letter-spacing alone: any value turns the notation back into letters.
