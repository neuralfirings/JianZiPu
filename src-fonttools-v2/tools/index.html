JianZiPu builder tools

Self-contained, offline HTML tools — no server or build tooling needed.

Font tester →

Live-test a built .ttf in the browser: type JianZiPu input, see it shape and render immediately. Example chips across basic words, decimals, modifiers, chords, vertical words, and Chinese input.

JianZiPu Font Builder →

Load a layouts.json + component SVGs, preview how glyphs sit in each layout area using the font's exact placement rule, then drag/resize areas and export a corrected layouts.json — no Figma access needed. Also builds the font directly (via python -m jzpbuild.devserver).

Dynamic Layout Editor →

Visual editor for dynamic_positioning/'s relationship graph (geometry.py's LAYOUTS): drag edges to author base→elem gap relationships, reorder/toggle optional areas, resize areas (shared across all layouts), and preview per signifier — all positions computed by the real chain.py/ anchors.py resolver.
